# Custom LongInt type realisation

## Детали реализации

  Пользовательский тип для целого знакового числа фиксированной длины **int2023_t**.
  Размер типа не превышает 253 байтa. Проект выполнен **без** использования стандартных контейнеров (std::vector, std::list и тд) и std::bitset.

  Реализован следующий набор функций и операторов:

     1. Конвертация из типа int32_t
     2. Конвертация из строки
     3. Сложение
     4. Вычитание
     5. Умножение
     6. Деление
     7. Вывод числа в поток

## Структура проекта

Проект состоит из трех директорий:
- **bin**
- **lib**
- **tests**

Требуется:
  1. **int2023_t** описан в заголовочном файле **lib/number.h**
  2. Функции и операторы реализованы в **lib/number.cpp**

В директории **bin** находится консольное приложение, которые вы можете использовать по вашему усмотрению.

### Тесты

Проект содержит базовый набор тестов, который позволит убедиться, что реализация функций выполненна без явных ошибок.
Для запуска тестов в командной строке можно выполнить след операцию:

***cmake --build . --target number_tests && ctest -V***  или воспользоваться средствами вашей IDE
